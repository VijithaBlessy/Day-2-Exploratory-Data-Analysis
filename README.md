# Day 2 – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Sample Superstore dataset as part of the VEDA Data Analytics Internship.

## Objective
To identify important patterns, relationships, outliers, and trends within the dataset using visual and statistical analysis.

## Dataset
- Dataset: Sample Superstore
- Records: 9,994 rows
- Columns: 21

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset information and summary statistics
- Sales distribution analysis
- Total sales by region
- Total sales by product category
- Total profit by region
- Monthly sales trends

## Top 3 Insights
1. The West region has the highest total sales and profit.
2. Technology is the highest-selling product category.
3. Monthly sales fluctuate, with the highest peak occurring in December 2017.

## Project File
- `Day_2_Exploratory_Data_Analysis.ipynb` – Notebook containing the EDA code, visualizations, observations, and insights.

## Conclusion
This project helped me gain practical experience in Exploratory Data Analysis and understand how data visualization can reveal useful business insights.
